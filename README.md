# Palindrome Checker App
This app has 13 usecases as follows

## Use Case-01:Application Entry & Welcome Message
This is the entry point of the Palindrome Checker Management System

## Use Case-02:Print a Hardcoded Palindrome Result
Demonstrates basic palindrome validation using a simple loop

## Use Case-03:Palindrome Check Using String Reverse
Checks whether a string is palindrome or not by reversing the string 

## Use Case-04: Character Array-Based Palindrome Check
Converts a string to a character array and compare characters using two pointers

## Use Case-05:  Stack-Based Palindrome Checker
Validates a palindrome using stack which follows a LIFO principle\
Pushes characters into a stack and pops them for comparison

## Use Case-06: Queue + Stack Based Palindrome Check
Validates a palindrome using stack and queue\
They are compared by removing from front of queue and top of stack

## Use Case-07: Deque-Based Optimized Palindrome Checker
Validates a palindrome using deque(double ended queue)\
Characters are inserted into deque and compared by removing elements from both ends

## Use Case-08: Linked List-Based Palindrome Checker
Validates a palindrome using a linked list\
Characters are inserted into list and compared by removing elements from both ends

## Use Case-09:Recursive Palindrome Checker
Validates a palindrome using recursion\
Characters are compared from outer positions moving inwards using recursive calls

## Use Case-10:Case-Insensitive & Space-Ignored Palindrome
Validates a palindrome after preprocessing the string\
Normalization includes removing spaces, symbols and converting to lowercase

## Use Case-11: Object-Oriented Palindrome Service
Demonstrates palindrome check using object oriented design \
Palindrome logic is encapsulated inside a palindrome service class

##  Use Case-12:Strategy Pattern for Palindrome Algorithms
Demonstrates how different plaindrome validation algorithms\
Can be selected dynamically at run time using strategy pattern

## Use Case-13:Performance Comparison
This class measures and compares the execution performance of palindrome algorithms\
Calculates total execution duration and displays benchmarking results
